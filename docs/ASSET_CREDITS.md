تُنسخ الملفات من `public/` إلى `hosting/public/` عند `npm run build`؛ لا تعدّل نسخة `hosting/` باليد. صور الخامات لا تُطلب إلا عند فتح منظور 3D. حافظ على سجل المصدر والترخيص لأي أصل جديد، حتى عند استخدام أصل CC0.
