# خطة تنفيذ الصوت — ١٠ مهام متقطعة

**التاريخ:** 5 نوفمبر 2026. طلب المالك: البدء بمرحلة الصوت وتقسيمها لنحو عشر مهام وعرضها.
**حالة هذا الملف:** خطة مع سجل تنفيذ فعلي أدناه. المهام ١–٨ نُفذت واختُبرت آليًا، و٩–١٠ منفذتان جزئيًا بسبب حالات اللاعب غير الموجودة وتجارب الأجهزة الحقيقية.
**الموجود قبل التنفيذ (تاريخي):** التقاط مايك ومعايرة RMS فردية خمس ثوانٍ، وإبلاغ انقطاع الجهاز. إشارة ضوضاء الأبواب تحرك AI، لكن لا صوت مسموع بعد.
**الثوابت:** صفر تكلفة، لا تسجيل/تخزين صوت خام، STUN فقط بلا TURN، قرب ٨م، تخفيف الجدران لا قطع الصوت، ولا زر كتم أثناء الجولة.

المؤثرات مولّدة إجرائيًا وليست إنتاجًا صوتيًا نهائيًا. لا TURN، ولا ضمان صوت عبر CGNAT.
**نقطة التوقف التالية:** مراجعة الصوت على جهاز حقيقي وإغلاق ملاحظات الخلط/الاتصال، ثم ربط سياسات حالات اللاعب عند تنفيذ القلوب والإحياء.
