# DARK SIGNAL / دار الصمت

نموذج رعب تعاوني عربي في المتصفح: 2–4 لاعبين، غرف خاصة، حركة وذكاء اصطناعي ودورة لعب بسلطة الخادم، وصوت قرب WebRTC إلزامي. يوجد اختبار فردي منفصل لا يغيّر الحد الأدنى للتعاون.

## الوضع الحالي

دورة اللعب الخلفية مرتبطة بالواجهة: ثلاثة قلوب وسقوط، إنقاذ متصل 10 ثوانٍ وفرصة أخيرة، ذخيرة وصعق، أربعة أدلة وكود بوابة، إنقاذ سليم واتباعه وفقدانه، هروب فردي ومشاهدة ونتائج وإعادة لعب. صلاحية المالك اختيارية على الخادم ومعطّلة ما لم يُضبط verifier سري.

**لم تُنشر خدمة عامة بعد.** إعداد Render موجود؛ المعاينة المحلية ليست رابطًا عامًا مضمونًا. الخريطة blockout، وليست الفن النهائي أو تجربة 30 دقيقة تم اختبارها بشريًا.

## تشغيل محلي

Node.js 22، ثم:

```bash
npm ci
npm run typecheck
npm test
npm run build
npm start
```

افتح `http://localhost:3000` محليًا. للوصول من جهاز آخر يلزم HTTPS ليعمل الميكروفون؛ في Arena استخدم بطاقة المعاينة. للإنتاج اضبط `ALLOWED_ORIGINS` إلى أصول HTTPS الفعلية. لا تضع أسرارًا في ملفات العميل أو Git.

## الاختبار

```bash
npm run test:e2e  # خمس حالات Chromium بصوت اصطناعي فعلي، AI ثابت في fixture فقط
npm run test:load # محاكاة CPU مسرّعة، ليست اختبار سعة شبكة/Render
```

59 اختبار وحدة/تكامل و5 اختبارات متصفح نجحت محليًا. التصادم والحركة والمواضع والأهداف والذخيرة والقلوب والأكواد يتحقق منها الخادم. الصوت STUN-only بلا TURN؛ قد يفشل عبور بعض الشبكات. فقد الميكروفون يجمّد بلا طرد، وانقطاع الشبكة يسمح باستئناف خلال 30 ثانية. لا تخزين صوت خام، ولا قاعدة بيانات أو حفظ غرف بعد إعادة التشغيل.
